# Almuqbil UI Redesign

This repository contains frontend templates and static assets for redesigning the Almuqbil management system interface.

Scope:
- HTML Templates
- CSS
- JavaScript
- User Interface Improvements
- User Experience Enhancements

Backend logic, database models, business rules and server configuration are not included.

Main goal:
Transform the transaction page into an Excel-like interface.

Requirements:
- Fast data entry
- Simple workflow
- Spreadsheet style layout
- Minimal clicks
- Mobile friendly
